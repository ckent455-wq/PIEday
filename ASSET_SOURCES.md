# Asset sources

- **DINER:** user-provided `DINER.rar`; Collada model and textures in
  `assets/DINER`. Texture references were repaired for portable relative paths.
  No license or attribution file was included in the supplied archive.
- **Base Humanoid Mesh:** user-provided `Base Humanoid Mesh.zip` / `Humanoid.blend`.
  The original editable source is preserved in `art/customer/source/`. The
  customer was clothed, posed, and rigged in Blender from that mesh. No license
  file was included in the supplied archive.
- **Food Inventory Sprites – 50 Pack by Polyy:** CC0; included license and README
  in `assets/food/food_inventory_sprites_50_pack/`. The golden meat pie sprite
  informed the new Blender pie's appearance.
- **Service-bell sound:** user-provided `609722__theplax__desk-bell.wav`,
  downloaded October 28, 2026; included as `assets/audio/service_bell.wav`.
  Creator name in the source filename: theplax. No license file was supplied.
- **Pie, cafeteria tray, and customer modifications:** created
  for this project. Editable Blender files and generation scripts are in `art/`.

This file records provenance; it does not relicense third-party material.

- **Closing encounter audio:** original synthesized knocking, footstep and
  cooler-creak effects in `assets/audio/closing_*.wav`, generated by the
  reproducible standard-library script `art/closing_audio/build_audio.py`.
  No third-party audio samples are used in these three effects.

- **Customer appearances:** user-provided `PSX_Rigged_Character_Bases1.2.rar`
  and `new heads.zip`, downloaded October 30, 2026. Six clothed male/female
  variants combine supplied pants/skirt rigs, clothing textures, and new heads.
  Used Blender, FBX, and texture sources are in `art/customer_psx/source/`;
  reproducible conversion is `art/customer_psx/build_customers.py`.
  Portable GLBs and extracted textures are in `assets/customers/`.
  Deform weights are retained, control rigs removed from runtime exports,
  textures reduced to 256px with nearest filtering. No separate license file
  was found in the supplied archives. The older humanoid remains the source
  for the closing encounter figure.

- **Refusal encounter:** the same user-provided PSX pack's adult male and female nude rigs
  and matching body textures, retained in `art/customer_psx/source/`, exported as
  `assets/customers/adult_unclothed.glb` and `adult_female_unclothed.glb`. Used for the clothing-required refusal
  event; uses the same skeleton and walking implementation as regular customers.

- **Intro typewriter:** user-provided `Text Typerwriter.zip`. The included
  `atwriter.ttf` font and `keyPress.wav` sound are in `assets/typewriter/`.
  Godot implementation adapts the per-character playback and volume variation
  from George Blackwell's 2019 `TextTyper.cs`. Original source is preserved in
  `art/typewriter/`; its MIT notice is in `assets/typewriter/LICENSE.txt`.
  No separate font or audio license file accompanied those supplied assets.

- **Shift clipboard:** modeled in Blender for this project using the
  user-provided `clipboard.jpg` as a visual reference. Reference, generation
  script, and editable `shift_clipboard.blend` are in `art/clipboard/`.
  The game-ready model is `assets/clipboard/shift_clipboard.glb`.

- **Outdoor dumpster:** user-provided `Trash Dumpster.glb`, downloaded
  October 29, 2026. Original preserved in `art/dumpster/source.glb`;
  normalized portable model in `assets/dumpster/dumpster.glb`.
  No license or attribution file accompanied the supplied model.

- **Morning-duty trash bag:** user-provided `Retro PSX Trash bag update.zip`,
  downloaded October 29, 2026. Original FBX variants and color textures are
  preserved in `art/trashbag/source/`. Converted to self-contained GLBs in
  `assets/trashbag/` with the supplied black texture and 0.55m height.
  Variant A replaces the morning-duty placeholder; variant B is also available.
  No license or attribution file was included in the supplied ZIP.

- **Hospital room:** user-provided Hospital_assets.zip, downloaded November 2, 2026. Bed, IV equipment, furniture and modular room kit exported from hospital.blend into assets/hospital/ with embedded 256 px textures. Rebuild notes: art/hospital/README.md.

- **Grandpa:** PSX rigged male body with the new-heads pack's bald m_head10 mesh and selected elderly D28 face texture. Exported as assets/customers/grandpa.glb; grandpa.tscn stores his resting arm pose and is instanced under Furniture/Bed in hospital_room.tscn.

- **Dialogue font:** Press Start 2P by the Press Start 2P Project Authors, distributed under SIL Open Font License 1.1. Font and full license are in assets/ui/. Source: https://github.com/google/fonts/tree/main/ofl/pressstart2p .

- **Death-ending background:** generated for PIEday with the imagegen skill, November 2, 2026; anatomy-corrected morgue image with a Grandpa toe tag. Runtime asset: assets/ui/death_grandpa_morgue.png.

- **Yard monster:** user-owned Pxltiger Zombie pack from C:/Users/jkern/HorrorP/Assets/Zombie. Previously converted zombie_1.glb is preserved as art/monster/source.glb. The runtime assets/monster/yard_stalker.glb retains the textured body and idle animation; editable source and preparation script are in art/monster/. This record does not expand the original asset's license.

- **Doorway sequence audio:** original synthesized bag impact and shadow sting/breath, generated by art/closing_audio/build_doorway_audio.py. No third-party recordings used.

- **Soda pouring:** Fizzy Drink Pouring Into Glass by Rudmer_Rotteveel, Freesound sound 700351, https://freesound.org/people/Rudmer_Rotteveel/sounds/700351/ , CC0 https://creativecommons.org/publicdomain/zero/1.0/ . User selected option 2. Public HQ MP3 preview preserved in art/soda_audio/freesound-700351-preview.mp3. Converted to mono, trimmed from 0.15 to 1.95 seconds, gain adjusted, with short fades by art/soda_audio/prepare_pour.py; runtime assets/audio/soda_pour.wav.

- **Coffee pouring:** Pouring coffee by Maajora, Freesound sound 432775, https://freesound.org/people/Maajora/sounds/432775/ , CC0 https://creativecommons.org/publicdomain/zero/1.0/ . User selected option 2. HQ MP3 preview preserved in art/coffee_audio/freesound-432775-preview.mp3. Mono 2.5-second extract (0.15-2.65s), gain and fades prepared by art/coffee_audio/prepare_pour.py; runtime assets/audio/coffee_pour.wav.

- **Oven ready bell:** toaster oven ding.wav by sethlind, Freesound 265012, https://freesound.org/people/sethlind/sounds/265012/ , CC0 https://creativecommons.org/publicdomain/zero/1.0/ . HQ MP3 preview preserved in art/oven_audio/freesound-265012-preview.mp3; mono WAV with leading silence removed and gain adjusted by art/oven_audio/prepare_ding.py. Rings once at the five-second perfect-bake threshold.

- **Diner music — Counter Service:** original 16-bar composition created for PIEday in BeepBox at 116 BPM. Electric piano melody, honky-tonk accompaniment, acoustic bass, and soft drums. Editable song JSON and BeepBox URL preserved in art/music/. Stereo WAV rendered with BeepBox's synthesizer; no third-party song or audio samples used.

- **Night music — Last Customer:** original BeepBox composition for PIEday, 58 BPM, sparse minor-key piano, dark sustained harmonics and low triangle drone. Editable JSON and BeepBox URL in art/music/; runtime assets/music/last_customer.wav. No third-party musical recordings.

- **Mop scrubbing:** Mopping the floor.wav by BeeProductive, Freesound 395603, https://freesound.org/people/BeeProductive/sounds/395603/ , CC0 https://creativecommons.org/publicdomain/zero/1.0/ . User selected option 1, friction only. Source HQ MP3 preview in art/mop_audio/; 12.05-13.65s excerpt, low handling rumble/high clinks reduced, mono gain and seam fades by prepare_scrub.py. Runtime assets/audio/mop_scrub.wav plays only while actively scrubbing kitchen/bathroom floors.

- **Haunted cooler opening:** fridge_door_open.WAV by naxxfish, Freesound 121210, https://freesound.org/people/naxxfish/sounds/121210/ , CC0 https://creativecommons.org/publicdomain/zero/1.0/ . User selected option 1. HQ MP3 preview preserved in art/cooler_audio/; mono/gain adjusted with leading silence trimmed by prepare_open.py. Runtime assets/audio/cooler_open.wav replaces the synthesized haunted cooler creak.

- **Hospital music — Still Here:** original sentimental piano composition for PIEday, created with BeepBox, 58 BPM in 3/4, sixteen bars (about fifty seconds). Grand piano melody and broken chords with a quiet string-like layer. Editable JSON and BeepBox URL are in art/music/; runtime assets/music/still_here.wav. No third-party musical recordings.
