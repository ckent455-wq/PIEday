FOOD INVENTORY SPRITES - 50 PACK
============================================================

50 cooked dishes as pixel-art sprite sheets, generated with polyy.ai.

Every sheet is a transparent PNG laid out 8 columns wide, 30 rotations
per item (12 degree steps), read left-to-right then top-to-bottom.

FOLDERS
  sprite/<size>_<lighting>/<item>_<coloring>.png
      48px, 64px and 96px, in studio and sun lighting, in five colorings:
      nopalette (high colour), 16-bit, 16-bit_dither, voyager, voyager_dither
  normals/<size>/<item>.png      tangent-space normal map, OpenGL Y+
  heightmaps/<size>/<item>.png   8-bit greyscale depth

  The normal and height maps line up with the sprite sheets frame for
  frame, so the same cell index works across all three.

ENGINE NOTES
  Import with filtering off (nearest) to keep the pixels crisp.
  Godot 4:  Import > Preset > 2D Pixel.
  Unity:    Filter Mode = Point, Compression = None.
