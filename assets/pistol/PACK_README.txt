3D LOW-POLY GUNS PACK 2
============================================================

25 low-poly gun models in GLB format with PBR textures, generated with polyy.ai.

These are the full-detail meshes: symmetrized, ~50k triangles, PNG PBR textures.

Two fidelities are published on the itch.io page:
  - 3D_low_poly_guns_pack_2.zip      full-detail meshes (~50k triangles each)
  - 3D_low_poly_guns_pack_2_low.zip  decimated LOD meshes (~25% triangles, hidden faces culled, JPEG textures)
Mix and match: use the low set for distant LODs, mobile, or crowded scenes.

ENGINE NOTES
  Godot 4:  drop the .glb into the project; import as Scene (Y-up, metres).
  Unity:    import the .glb with glTFast or UnityGLTF.
  Unreal:   File > Import with the glTF importer.
  Muzzles point along -X; models are centred on the origin, roughly 1 unit long.
